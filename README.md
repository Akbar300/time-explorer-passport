# Time Explorer Passport

Interactive 5th-grade world cultures study app.

**Live app:** https://akbar300.github.io/time-explorer-passport/

It deploys to GitHub Pages automatically on every push to `main`. To run it locally instead, open `index.html` in a browser (keep the `img/` folder next to it).

Features:
- Hero scenes for ancient civilizations
- Character guides
- GRAPES visual icons
- Passport stamps and progress tracking
